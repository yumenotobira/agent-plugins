# 機能追加・改善のテンプレート

新機能、既存機能の改善、仕様変更を提案するときに使う。

```markdown
## 背景・目的
<!-- なぜ必要か。誰が何に困っているか -->

## やりたいこと
<!-- 実現したい状態。手段より目的を先に -->

## 案
<!-- 任意。実装方針や代替案、検討したが採用しない案 -->

## スコープ外
<!-- 任意。この issue ではやらないこと -->

## 完了条件
- [ ]
```

## 書くときの注意

- 「やりたいこと」には実現したい状態を書き、実装方法は「案」に分ける。目的が伝われば、より良い手段を選べる。
- スコープが広がりそうなら「スコープ外」を明記し、別 issue に切り出す。

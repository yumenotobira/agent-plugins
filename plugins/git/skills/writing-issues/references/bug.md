# バグ報告のテンプレート

不具合・エラー・期待と異なる動作を報告するときに使う。

```markdown
## 概要
<!-- 何が起きているかを 1〜2 文で -->

## 再現手順
1.
2.
3.

## 期待する動作

## 実際の動作
<!-- エラーメッセージやログはそのまま貼る -->

## 環境
<!-- OS, バージョン, ブランチ/コミットなど、関係するもの -->

## 調査内容と結果
<!-- 任意。起票時点で調査済みのことがあれば書く。何を確認して、何が分かったか -->
- 確認したこと:
  - 結果:

## 原因の推測・補足
<!-- 任意。推測であることを明記 -->

## 完了条件
- [ ] 再現手順で期待する動作になる
- [ ] 回帰テストを追加する
```

## 書くときの注意

- 再現手順は、初めて見た人がそのまま実行できる粒度で書く。再現しない・条件不明の場合はそう明記する。
- エラーメッセージやスタックトレースは要約せず原文を貼る。長い場合は `<details>` で折りたたむ。
- 環境は、バグに関係しうるものだけ書く。
- 「調査内容と結果」には、起票時点で実際に確かめたことだけを書く。確認した内容（読んだコード、試した操作、実行したコマンドなど）と、その結果をセットで書く。
  - 「問題なかった」「再現しなかった」という結果も書く。原因の候補を絞り込む手がかりになり、同じ調査を繰り返さずに済む。
  - 結果から考えた原因は、「原因の推測・補足」に分けて書く。
  - 調査していなければ、このセクションは省く。
